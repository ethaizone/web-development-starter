## Learning strategies

1. **Build projects.** Reading without building doesn't stick. Every new concept
   → build something small.
2. **Read source code.** Open-source projects on GitHub show you how experienced
   developers structure code.
3. **Break things on purpose.** Delete code, change values, remove types — see
   what breaks and why.
4. **Use AI as a tutor, not an oracle.** Ask "why does this work?" and "what
   would happen if I changed X?" instead of just getting answers.
5. **Teach what you learn.** Write a blog post, explain to a friend, or
   contribute to docs. Teaching reveals gaps in understanding.
