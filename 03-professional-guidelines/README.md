# Pro Guidelines

**"What should I learn next?"** — A curated map of professional topics you'll
encounter as a web developer. Not a course. Read in any order, skip what you
already know.

## How to use this

- **Skim first**, then deep-dive into topics relevant to your current work.
- Each topic links to official docs and trusted resources — we don't re-teach
  what's already well-documented.
- No exercises here. Go read the linked resources, try things, break things.
