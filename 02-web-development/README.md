# Web Development Track

## How This Track Works

The TS Track (01) is **learning by doing** — read the
concept, run the example, try the exercise.

This track is different. It's **learning from how we created** — you read
through a record of what we built, step by step, to arrive at the
[DevStack Bio reference app](../devstack-bio-reference/).

Each module documents:

1. **Key Concepts** — the ideas behind what we're about to build
2. **What We Built** — the actual code we wrote and commands we ran, in order

You don't need to type along. Read the concepts, study the code, and explore the
reference app to see the full picture. If something is unclear, ask an AI to
explain it differently.

Think of it as reading someone's build journal — not following a tutorial.

## The End Goal

The reference app (`devstack-bio-reference/`) is the finished product. Browse
its source code anytime to see how everything fits together.

## Prerequisites

- Completed the TS Track (Modules 01–10 minimum)
- Node.js 24 LTS installed
- A code editor (VS Code recommended)
